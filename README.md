# Get started with Zoom Apps SDK

This repository hosts a Google Codelab that walks through building a Zoom App with Next.js and the Zoom Apps SDK. The tutorial demonstrates how to extend a web application into the Zoom client, configure the app via the Zoom Manifest API, and integrate Supabase for authentication.

## What you'll learn
- Structure and configure a manifest JSON for Zoom Apps.
- Implement secure API communication using OAuth scopes and webhook endpoints.
- Manage manifest versioning during updates.
- Expose local Next.js and Supabase services over HTTPS with ngrok.

## Prerequisites
- Git
- Node.js
- Zoom account with developer role permissions
- Supabase account with developer role permissions
- Development workspace with permissions to install apps

## Getting started
Open `index.html` in a browser and follow the step-by-step instructions. The codelab covers creating a user-managed Zoom Marketplace app, updating it via the Manifest API, starting ngrok tunnels, and configuring Supabase for authentication.
